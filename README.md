# 🩸 **DBD Perk Bot**

🎮 *Discord-бот для Dead by Daylight, який генерує рандомні білди, керує перками та профілем гравця.*

---

## ⚙️ **Команди**

| Команда | Опис |
|:--|:--|
| 🎲 `!dpsm` | Згенерувати білд вижившого. |
| 🌍 `!lang [ua\|en\|fr]` | Змінити мову інтерфейсу. |
| ❌ `!dhtp 1 2 3 4` | Позначити перки, яких у тебе немає (з останнього білду). |
| ✍️ `!dhtc [Character Name]` | Позначити персонажа, якого ти не маєш. |
| ✅ `!ihave [сharacter name\|index(1 2 3 4)]` | Додати перк у список наявних. |
| 📋 `!missing` | Показати, які перки тобі ще бракує. |
| ♻️ `!resetperks` | Скинути список своїх перків. |
| 🎚️ `!mode random\|meta\|troll\|streamer` | Змінити режим генерації. |
| 👤 `!profile` | Переглянути профіль гравця. |
| 🆘 `!help` | Показати довідку. |

---

## 🧩 **Режими гри**

| Режим | Опис |
|:--|:--|
| 🎲 **random** | Звичайний випадковий набір перків. |
| 🔥 **meta** | Найпопулярніші мета-білди. |
| 😈 **troll** | Кумедні або нестандартні білди. |
| 📺 **streamer** | Білди на основі стрімерських гайдів. |
| 🧠 **solo / forteams / advanced** | Розширені режими з Otzdarva-білдів. |

---

2. Вкажи токен у `config.json`
3. Збери проєкт:
